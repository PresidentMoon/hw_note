# 필체 노트

여자친구 필체로 대필하는 노트앱 (갤럭시 탭 · 아이패드 브라우저용)

## 파일
- `index.html` : 필체 노트 (필기, 양식 PDF 불러오기, 대필, 올가미, 노트북, 저장)
- `label.html` : 라벨링 도구 (필체 데이터 → 학습 데이터)
- `pack.json` : **필체 팩** — 직접 추가하세요 (아래 참고)
- `manifest.webmanifest`, `*.png` : 홈 화면 앱 아이콘

## 필체 팩 넣기
1. 컴퓨터에서 `python hw_pack_v3.py` 실행 → `out/필체팩_여자친구.json` 생성
2. 이 파일 이름을 **`pack.json`** 으로 바꿔서 이 저장소에 업로드
3. 사이트를 열면 자동으로 불러와요. 모델을 새로 학습하면 같은 방법으로 교체하면 자동 업데이트돼요.

## GitHub Pages 켜기
Settings → Pages → Branch `main`, 폴더 `/ (root)` → Save
주소: `https://<아이디>.github.io/<저장소 이름>/`

## 필체 데이터 모으기
노트앱 설정 → **필체 데이터 다운로드** (모든 노트의 손글씨만) → 라벨링 도구의 **노트 파일 열기** → 학습 데이터 내보내기
